# 🚀 Projeto Coinbase

Projeto desenvolvido para explorar conceitos de programação e análise de dados relacionados ao mercado de criptomoedas e à plataforma Coinbase.

## 📌 Sobre o projeto

O objetivo é aplicar conhecimentos de programação e Ciência de Dados por meio de um projeto prático, explorando dados e ferramentas relacionadas ao universo das criptomoedas.

## 🎯 Objetivos

- Praticar conceitos de programação.
- Explorar dados relacionados ao mercado de criptomoedas.
- Desenvolver habilidades de análise e organização de dados.
- Aplicar conhecimentos de Ciência de Dados.
- Utilizar o Git e o GitHub para versionamento de código.

## 🛠️ Tecnologias

As tecnologias utilizadas podem ser consultadas nos arquivos do projeto.

## ⚙️ Como executar

Clone o repositório:

```bash
git clone https://github.com/FranciscoM-uv/Projeto_coinbase.git
```

Entre na pasta:

```bash
cd Projeto_coinbase
```

Instale as dependências necessárias e siga as instruções de execução de acordo com a estrutura do projeto.
